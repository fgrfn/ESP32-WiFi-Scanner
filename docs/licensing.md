# License options

The owner must choose a license before publication. In addition, because the
firmware started from Arduino code distributed with a MakerWorld project, the
license of that original source—or explicit permission from its creator—must be
confirmed first. See [`ATTRIBUTION.md`](../ATTRIBUTION.md).

| License | Practical effect |
|---|---|
| MIT | Short, permissive, allows proprietary reuse with copyright/license notice. |
| Apache-2.0 | Permissive like MIT, plus an explicit patent grant and notice rules. |
| GPL-3.0 | Strong copyleft; distributed modified/derived binaries must provide corresponding source under GPL-3.0. |

**Suggested default:** MIT for the simplest broad reuse, or Apache-2.0 if the
explicit patent terms are desirable. Choose GPL-3.0 when keeping distributed
derivatives open is a project goal.

This is a project-maintenance summary, not legal advice. Dependency licenses
remain separate and must be respected.
