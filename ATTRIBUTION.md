# Attribution and project origin

ESP32 WiFi Scanner was inspired by and initially based on the Arduino code distributed
with Marco's MakerWorld project:

- **WIFI ANALIZER - ESP32 LVGL 2432S028 2.8\"**
- Creator: **Marco**
- Source: <https://makerworld.com/de/models/2303837-wifi-analizer-esp32-lvgl-2432s028-2-8#profileId-2514600>

The firmware in this repository was subsequently and substantially extended
with additional scanning, display, analysis, persistence, logging, dashboard,
time synchronization, and usability features.

The MakerWorld project also provides a printable enclosure for the compatible
ESP32 display. This repository does not redistribute that enclosure or any STL,
3MF, STEP, or other model file; users should obtain it from the original page
and follow the license shown there.
